# Khalid Eldhrawy — Performance Marketing Portfolio

Static, dependency-free portfolio built with semantic HTML, CSS, and vanilla JavaScript.

## Update content

- Edit `assets/projects.js` to add a case study, update its verified results, or change the additional-work projects.
- Replace the `PORTRAIT PLACEHOLDER` in `index.html` with a real high-contrast black-and-white portrait when one is ready.
- Update the WhatsApp, email, LinkedIn, and canonical URLs in `index.html` before publishing.

The site deliberately uses `[ VERIFIED ... NEEDED ]` and `DATA AVAILABLE ON REQUEST` where detail was not provided. Replace those only with verified campaign data.

## Preview

Open `index.html` in a browser. No build step is required.
